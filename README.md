# Our apartment fund

A small savings tracker with a progress ring, preset deposits, withdrawals, goal changes and fireworks.

## Deploy on GitHub Pages
1. Create a new repository on GitHub (for example `apartment-fund`).
2. Upload `index.html` and `README.md` to it (Add file, Upload files).
3. Open Settings, then Pages. Under "Build and deployment" choose "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
4. After a minute your app is live at `https://YOUR-USERNAME.github.io/apartment-fund/`.

## Important
- Data is stored in each browser (localStorage), so Ruben and Leta do not see each other's entries.
- Use "Download backup" in Advanced settings regularly. "Restore" loads a backup file.
- GitHub Pages on a free account needs a public repository, so the page is public. The data is not, because it never leaves your browser.
